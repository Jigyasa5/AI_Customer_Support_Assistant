# AI Customer Support & Knowledge Assistant

An AI-powered customer support assistant using **NLP, Transformers, Embeddings, Vector Search, and RAG** to answer customer queries from trusted knowledge documents.

## Features

- NLP preprocessing and intent classification
- BERT/Sentence Transformer embeddings
- PDF, TXT, and DOCX document processing
- Document chunking and vector search
- ChromaDB integration
- RAG-based question answering
- Conversation memory and query rewriting
- Hybrid search and reranking
- Metadata filtering and source citations
- RAG guardrails and hallucination handling
- RAG evaluation and user feedback
- FastAPI backend and Docker deployment

## Tech Stack

Python | NLP | Transformers | Sentence Transformers | ChromaDB | RAG | FastAPI | Docker

## Project Goal

Build a reliable AI customer-support system that provides **grounded answers from trusted documents with source citations**.
